# Space Simulator (2011)

**Historical project. Original source last modified: 15 May 2011.**

I built this C++ and OpenGL space simulator before my first professional software
engineering job. It helped me land that job and marks the beginning of my career.

The project combines gravitational simulation, orbital initialization, and
interactive visualization. It reflects an early interest in simulation and
building software from the underlying mathematics through to a working interface.
These are interests I continue to explore today with Arcanex and Rust.

The original source code is preserved unchanged, including its design choices and
limitations. This is a historical snapshot of my work at the time. For my current
projects, see [my GitHub profile](https://github.com/humacss).
